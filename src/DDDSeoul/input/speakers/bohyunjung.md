## 발표자 소개

MongoDB에서 APAC 지역을 담당하는 Senior Developer Advocate입니다. NAVER, 컬리 등에서 10년 넘게 검색과 AI 애플리케이션을 개발했고, 지금은 빌더들이 MongoDB로 아이디어를 실제 서비스로 만들 수 있도록 실습 워크숍과 기술 콘텐츠를 만들고 있습니다.

기술을 잘 만드는 것만큼 잘 전달하는 것도 중요하다고 생각합니다. 지역 개발자 커뮤니티와 오래 이어지는 관계를 만들어 가고 있습니다.

## 세션 정보

### 새 세션 켤 때마다 '처음 뵙겠습니다' 하는 AI 멱살 잡기: MongoDB로 구현하는 Agent Memory

Agent 서비스 품질을 프로덕션 수준으로 끌어올리려면 체계적인 메모리 설계가 필수적입니다.

본 세션은 Microsoft Justin Yoo 님의 [Interview Coach](https://aka.ms/mafinterviewcoach/blog) 예제를 출발점 삼아, 실무 관점에서 에이전트 메모리 구조를 확장해보는 과정을 다룹니다. 장단기 메모리 유형과 생애주기 관리 등 Agent Memory 설계 일반론을 먼저 짚어본 뒤, Interview Coach 프로젝트의 메모리를 MongoDB로 직접 구현해봅니다. 나아가 MongoDB for VS Code 확장에 내장된 MongoDB MCP를 활용해 DB를 실시간으로 탐색하는 흐름까지 살펴봅니다.
