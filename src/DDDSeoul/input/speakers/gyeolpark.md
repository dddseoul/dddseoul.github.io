Microsoft 365와 Microsoft AI 제품을 중심으로 교육하는 박결입니다. 한때 IT 엔지니어를 꿈꿨지만, 배우고 나누는 일에 더 끌려 강사의 길을 택했습니다. 지금은 AI 시대에 Copilot을 제대로 쓰는 방법을 알리고 있습니다.

## 세션 정보

### Copilot 에이전트를 코드로 커스텀하면, 추가 비용 없이 성능이 올라간다고요?

Copilot에서 일반 사용자가 에이전트를 만드는 도구는 크게 세 가지입니다. 그런데 셋 모두 아쉬운 점이 있습니다.

- GitHub Copilot Harness: 성능은 뛰어나지만 쓸 때마다 Copilot Credit이 차감되어, 모든 회사가 도입하기 어렵습니다.
- Copilot Studio Standard Harness: 만드는 과정이 복잡하고 런타임 성능에 한계가 있습니다.
- Agent Builder(선언적 에이전트): 만들기는 쉽지만 쓸 수 있는 기능이 적어 활용 폭이 좁습니다.

이 세션에서는 이 아쉬움을 모두 타파하는 "궁극의 방법"을 공유합니다. 선언적 에이전트의 manifest.json과 declarativeAgent.json을 직접 고치면, Agent Builder 화면에서는 켤 수 없던 기능을 넣을 수 있습니다. 그러면서도 추가 과금 없이 Copilot의 강력한 런타임을 그대로 씁니다.

하지만.. 커스텀 하는 방법이 어렵지 않냐고요?

전혀 그렇지 않습니다. 아주 손쉽게 강력한 무과금 에이전트를 만드는 방법을 이 자리에서 공개합니다.
