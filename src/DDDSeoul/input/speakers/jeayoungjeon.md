## 발표자 소개

현대오토에버에서 AI 플랫폼 엔지니어로 일하고 있는 6년차 개발자 전제영입니다. 회사에서는 차량 SW 개발을 돕는 AI 에이전트를 만들고 있습니다. 퇴근 후에는 GitHub Copilot과 라즈베리파이로 멋진 오픈소스를 만들고 있습니다.

## 세션 정보

### GitHub Copilot과 함께 키운 라즈베리파이 쿠버네티스, 그 위에 AI 에이전트 팀을 올리기

라즈베리파이와 GitHub Copilot으로 쿠버네티스 홈랩을 만들고, 그 위에 AI 에이전트 팀을 올렸습니다. 이 인프라와 워크로드를 실무에서도 쓸 수 있는 구성으로 가꾼 과정과 성과를 공유합니다.

1. **구성**: 클러스터의 모든 설정은 GitHub 저장소 하나에서 GitOps(ArgoCD)로 관리합니다. 복잡한 YAML과 Helm 차트 디버깅은 GitHub Copilot과 함께 해결해 왔습니다.

2. **관리**: 라즈베리파이 클러스터에는 냉각을 위한 팬 제어기가 필요합니다. 이를 위한 오픈소스 pifanctl을 구성했고, 라즈베리파이에서 직접 빌드하고 테스트할 수 있도록 GitHub Actions Runner Controller(ARC)로 클러스터 안에 CI/CD 러너를 올렸습니다. 그 밖의 운영도 GitHub Actions로 자동화했습니다.

3. **워크로드**: 오픈소스 Hermes Agent Helm 차트를 직접 만들어 에이전트 팀을 꾸렸습니다. 코딩 에이전트이자 팀 리더인 에이전트 Henry, 일상 비서인 에이전트 Victoria, 커리어 비서인 에이전트 Rouise, 클러스터 관리자인 에이전트 Hana가 각자의 역할로 함께 일합니다.

4. **데모**: 에이전트 Hana는 pifanctl과 클러스터 상태를 살피다가 온도 조절이 안 되거나 클러스터 상태가 나빠지면 저에게 먼저 알려 줍니다. 이 팀이 일을 주고받는 모습을 데모로 보여드립니다.

5. **레슨런**: 두 에이전트가 서로를 끝없이 호출하던 무한 루프, 두 번 접은 에이전트 팀처럼 실제로 겪은 실패와 거기서 얻은 운영 규칙도 나눕니다.

6. **확장**: 이 클러스터는 Azure AKS 같은 클라우드로 옮길 수도 있지만, 프로덕션과 실무를 위한 보일러플레이트이자 연습장으로 쓸 수 있다는 점이 더 큽니다. 개인 프로젝트를 실무에 활용하는 꿀팁도 공유드립니다.

개인 공부의 기록이 GitHub 포트폴리오가 되어 커리어에 도움이 된 이야기도 나눕니다. 중급 난이도이지만, AI와 쿠버네티스를 처음 접하시는 분도 편하게 들으실 수 있도록 쉽게 풀어서 소개합니다.
