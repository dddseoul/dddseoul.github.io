## 발표자 소개

Microsoft MVP이자 오픈소스 AI 번역 도구 Co-op Translator의 메인테이너입니다. Azure AI를 활용해 Microsoft의 개발자 교육 콘텐츠를 여러 언어로 번역하는 자동화 도구를 개발하고 운영하고 있습니다.

다양한 언어의 기여자들과 협업하며 번역 품질과 자동화의 안정성을 개선하고 있습니다. 실제 프로젝트에서 마주한 문제와 해결 과정, 오픈소스 유지보수 경험을 개발자 커뮤니티와 나누는 데 관심이 있습니다.

## 세션 정보

### 에이전트가 결정하고, 컨테이너가 실행한다: Microsoft Foundry와 Azure Container Apps Jobs로 만드는 신뢰할 수 있는 AI 워크플로우

AI 에이전트는 요청을 이해하고 계획을 세우는 데 뛰어납니다. 하지만 오래 걸리는 작업의 실행부터 실패 복구와 재시도까지 모두 에이전트에게 맡기는 것이 최선일까요?

이 세션에서는 다국어 문서 현지화 시스템 Localizeflow의 운영 경험을 바탕으로, 에이전트의 의사결정과 실제 작업 실행을 분리하는 아키텍처를 소개합니다.

먼저 기존 자동화만으로 충분한 작업과 AI 에이전트의 판단이 필요한 작업을 구분하고, 각각의 접근 방식을 선택하는 기준을 살펴봅니다.

이어서 Microsoft Foundry를 활용해 에이전트가 작업을 판단하고, Azure Container Apps Jobs를 통해 실제 작업을 격리된 환경에서 실행하는 구조를 살펴봅니다.

실제 사례와 아키텍처를 중심으로 이러한 역할 분리가 어떤 장점을 제공하는지 알아보고, 안정적인 워크플로를 설계하기 위한 기술 선택 기준을 공유합니다.

에이전트는 무엇을 해야 할지 결정하고, 컨테이너는 그 작업을 신뢰성 있게 실행합니다.

이 세션을 통해 두 역할을 분리하고 결합하는 실용적인 설계 방법을 함께 살펴봅니다.
