## 세션 정보

### 비개발자에게 날개를 달아준 GitHub Copilot

코딩을 잘 몰라도 내가 만들고 싶은 걸 직접 만들 수 있는 시대가 왔는데요!! GitHub Copilot과 함께 아이디어를 실제로 작동하는 결과물로 만들어보려고 합니다.

그렇지만 AI가 만들어줬다고 무조건 믿고 써도 되는 걸까요? 화면도 잘 나오고 실행도 잘 되는데, 알고 보니 문제가 있다면?!

직접 만들어보는 과정부터 놓치기 쉬운 함정, 그리고 꼭 알아야 할 검증과 테스트까지!

만드는 건 AI의 도움을 받아 할 수 있지만, 제대로 만들어졌는지 확인하는 것도 정말 중요하겠죠?

신나게 만들고, 꼼꼼하게 검증하는 GitHub Copilot 활용 꿀팁과 비개발자의 좌충우돌 검증방법! 함께 나눠보고자 합니다!!
