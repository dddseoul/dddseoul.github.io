### 레거시 ERP를 AI와 연결하기: .NET 기반 양방향 MCP 플랫폼 설계 경험

ERP를 직접 AI에게 열지 말고, AI 친화적인 Anti-Corruption Layer를 먼저 만드는 과정을 소개하고자 합니다.

많은 기업 ERP는 AI가 활용하기 어려운 형태로 구축되어 있습니다.

이 세션에서는 기존 ERP를 전면 재개발하지 않고,

- SQL Server CDC 기반 데이터 읽기(Read)
- 파일 기반 데이터 읽기(Read)
- ASP.NET Core 기반 데이터 쓰기(Write)

를 MCP(Model Context Protocol) 형태로 제공한 실제 설계 경험을 소개합니다.

또한 ALC(Assembly Load Context)를 활용하여 비즈니스 모듈을 독립 배포 가능하게 설계함으로써 서비스 재기동 없이 기능을 확장하고 운영 리스크를 줄인 경험을 공유합니다.
