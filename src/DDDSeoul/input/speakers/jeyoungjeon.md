## 발표자 소개

현대오토에버에서 AI 플랫폼 엔지니어로 일하고 있는 6년차 개발자 전제영입니다. 회사에서는 차량 SW 개발을 돕는 AI 에이전트를 만들고 있습니다. 퇴근 후에는 GitHub Copilot과 라즈베리파이로 멋진 오픈소스를 만들고 있습니다.

## 세션 정보

### GitHub Copilot과 함께 키운 라즈베리파이 쿠버네티스, 그 위에 AI 에이전트 팀을 올리기

취미로 GitHub Copilot과 함께 키운 라즈베리파이 쿠버네티스 홈랩이, AI 에이전트 팀이 일하는 프로덕션급 플랫폼이 된 사례를 공유합니다.

1. 클러스터의 모든 설정은 GitHub 저장소에서 GitOps(ArgoCD)로 관리합니다.
2. 필요하면 Azure AKS 등 클라우드로 쉽게 옮길 수 있도록 설계했습니다.
3. 복잡한 YAML과 Helm 차트는 GitHub Copilot과 함께 작성하며 문제를 풀어 왔습니다.
4. GitHub Actions Runner Controller(ARC)를 올려 라즈베리파이가 직접 CI/CD 러너로 동작합니다.
5. 도메인을 연동해 언제든 라이브 데모가 가능한 저만의 플랫폼을 갖추었습니다.
6. 이 클러스터 위에 Hermes Agent 팀을 구성하는 오픈소스 Helm 차트를 개발하고 있습니다. 에이전트의 두뇌 역시 GitHub Copilot이며, 역할이 다른 에이전트들이 함께 일하는 모습을 데모로 직접 보여드립니다.

취미와 개인 공부로 시작한 기록이 GitHub 포트폴리오가 되어 커리어에도 도움이 된 이야기도 함께 나눕니다. 중급 난이도이지만, AI와 쿠버네티스를 처음 접하시는 분도 편하게 들을 수 있도록 풀어서 소개합니다.
